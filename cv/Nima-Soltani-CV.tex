\section*{Voluntarily Activities}

\vspace{0.25em}
\subheader{Workshops}
\begin{itemize}[itemsep=0.55em,topsep=0.35em]
  \item \textbf{Fundamentals of Programming.}
    Pointers, dynamic memory, and recursion in C: memory layout, \texttt{malloc}/\texttt{free}, dangling pointers and leaks; recursion from base cases through the call stack, with backtracking and divide-and-conquer exercises.
  \item \textbf{Logic Circuits.}
    Combinational and sequential design: Boolean minimisation, building blocks, flip-flops, and finite-state machines, with designs checked in a simulation tool.
  \item \textbf{Linear Algebra.}
    SVD, PCA, and numerical methods in Python: decompositions in NumPy, PCA on real data, and why numerical stability matters in practice.
  \item \textbf{Advanced Programming.}
    Java OOP (classes, interfaces, polymorphism) and a small 2D Unity game in C\# organised with object-oriented patterns.
  \item \textbf{Data Structures and Algorithms.}
    Graph traversal and dynamic programming: BFS, DFS, and shortest paths; turning problems into recurrences solved with memoisation or tabulation.
  \item \textbf{Data Mining.}
    Practical sessions with scikit-learn on preprocessing, feature engineering, clustering, and classification, with attention to evaluation and data leakage.
  \item \textbf{Machine Learning Systems Engineering.}
    Reproducible ML pipelines: experiment tracking, configuration management, versioned data and models, and basics of packaging and deploying a trained model.
  \item \textbf{Principles of Design and Analysis of Experiments.}
    Experiment design and simulation in Python and R: randomisation, blocking, and factorial designs; simulation for effect sizes, power, and ANOVA.
  \item \textbf{Blockchain Technology.}
    Ethereum smart contracts and security: writing, testing, and deploying Solidity contracts; common vulnerabilities (reentrancy, access control) and how audits find them.
  \item \textbf{Computer Architecture.}
    Instruction set architecture and MIPS assembly: instruction formats, addressing modes, register conventions, and hand-written assembly for loops, procedures, and the stack.
\end{itemize}
